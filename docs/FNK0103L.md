# Freenove FNK0103L (experimental)

This target adapts SquachWatch to the Freenove FNK0103L 3.2-inch, 240×320
ST7789 IPS board with XPT2046 resistive touch. Using the standard 2.8-inch
build on the initial test unit produced inverted colors and no touch input.

Select `fnk0103l` explicitly in PlatformIO. It is compiled by CI but is not
in `default_envs`, the public web flasher, or the release publishing workflow.
Do not select the 3.5-inch `cyd35` target for this board.

## Build and install

```sh
pio run -e fnk0103l
pio run -e fnk0103l -t upload
pio device monitor -b 115200
```

Use a USB data cable. Upload and serial monitoring default to 115200 baud.
Back up the existing flash before first installation if settings or the
previous firmware need to be recoverable. Standard PlatformIO uploads keep
the NVS settings region; a whole-flash erase or padded merged image may not.

Complete the five-target calibration with a plastic stylus, holding each
target for approximately one second, then follow the verification prompt.
If it times out, reboot and try again. The `fnk32fit` and `fnk32cal` namespaces
isolate calibration from earlier builds for different wiring. Other existing
settings are preserved, including user inversion and color-order overrides.

## Wiring and behavior

| Function | Configuration |
| --- | --- |
| Display | ST7789, 240×320 native, BGR, inversion on |
| Display/touch bus | HSPI; MISO 12, MOSI 13, clock 14 |
| Display select / command-data / reset | 15 / 2 / -1 |
| XPT2046 select | 33; pressure-gated raw reads, no IRQ required |
| Backlight | GPIO27 only |
| RGB status LED | Red 22, green 16, blue 17; active low |
| SD bus | VSPI; MISO 19, MOSI 23, clock 18, select 5 |
| Display / touch clocks | 40 MHz / 2.5 MHz |

The display and touch share one SPI peripheral. Keeping the SD card on the
other peripheral avoids changing the display/touch bus during SD setup.
The application sets inversion relative to the IPS panel's baseline, so a
later settings update does not undo the initialization setting. GPIO4 is
not used for the red LED on this board; it controls the audio amplifier.

The hardware configuration follows Freenove's corresponding FNK0114L setup;
this target is named after the FNK0103L unit used for the initial test. Other
product labels and board revisions still need independent verification.
The display starts at 40 MHz rather than the vendor example's 80 MHz.

## Validation and remaining checks

The initial FNK0103L unit identified as ESP32-D0WD-V3 revision 3.1 with 4 MB
flash. All four uploaded firmware regions passed esptool hash verification,
and the tester confirmed normal colors, successful touchscreen calibration,
precise command/menu taps, and working BLE and Wi-Fi scans. The tester also
reported detection of AirTag, Flipper, and Cardputer ADV pings. These are
user-observed results on one unit, not independent signature validation.

Local validation includes builds of `fnk0103l` and `cyd`, plus the existing
host touch-fit tests. Remaining hardware checks include SD logging with touch
still responsive, brightness and RGB LED behavior, all screen rotations,
calibration persistence, and an extended Wi-Fi/BLE run without restarts.

This is a USB test target. It has its own OTA build identity, but there is no
published `fnk0103l` update feed or signed release. Update checks may report
that no build is available. Use USB for subsequent test builds.
