# Cardputer ADV hotkeys

The Cardputer's own screen is 240x135. Buttons are small and the cursor takes
a lot of arrow presses to get anywhere. Letters skip all of that: press the
first letter of a button and it is pressed.

Works the same with or without the EXT screen. Without it, this is the fast
way around.

## The four rules

1. **A letter presses the button whose label starts with it.** SCAN is S,
   HUNT is H, CANCEL is C.
2. **Two buttons with the same letter:** the key moves the cursor between
   them. ENTER presses the one it is on. Nothing is pressed by surprise.
3. **ESC is back. Hold ESC 3 seconds for home**, from anywhere, even while
   typing.
4. **On a text screen letters type.** WiFi password, PIN, names, messages.
   Hotkeys come back when you leave it.

## Keys that work everywhere

| Key | What |
|-----|------|
| ESC or DEL | Back one screen. On home, opens the menu |
| ESC held 3 s | Home |
| E | EXT screen on or off |
| B | Next background (not on the scan screens, see below) |
| Arrows (`;` `,` `.` `/`) or TAB | Move the cursor |
| ENTER or SPACE | Press what the cursor is on |

## Screen by screen

| Screen | Keys |
|--------|------|
| Home | **S** scan, **L** log, **D** desk. ESC opens the menu |
| Scan picker | **B** BLE, **W** WiFi, **S** closes it |
| WiFi scan | **B** switches to BLE. ESC back |
| BLE scan | **W** switches to WiFi. ESC back |
| Track this target (ENTER on a scan or log row) | **W** watch, **H** hunt, **I** ignore, **C** cancel. From the log also **M** more info. ESC cancels |
| Alert | **H** hunt, **S** snooze (again for longer). **I** steps between INFO and IGNORE, ENTER presses |
| Hunt | **S** stop. ESC back |
| Log | **S** or **L** back home. Arrows pick a row, ENTER opens it |
| Desk | **F** focus timer. ESC back |
| Settings | No letters. Arrows and ENTER, ESC back |

**CLR on the log has no letter on purpose.** It wipes the log with no
question asked, so it takes the arrows and ENTER.

## Without the EXT screen: the quick ways

| To | Press |
|----|-------|
| See WiFi around you | S, W |
| See Bluetooth around you | S, B |
| Hunt a device from its alert | H |
| Quiet a device that keeps alerting | S (once 10 min, again for 30 min, 1 hour, 4 hours) |
| Track something from a scan | arrows to the row, ENTER, then W or H |
| Get home from anywhere | hold ESC |
| Change the look | B on home |
| Check the log | L |

## With the EXT screen

Squachy and the full home move to the big screen. The built-in screen becomes
a still home that lists these keys, so the letters keep working from it. E
turns the big screen off; the built-in screen goes back to normal.
