The bitmap atlas is derived from Noto Sans CJK TC Regular, version Sans2.004.
It covers the font's BMP Han characters and the included Chinese punctuation
and Bopomofo ranges. The SIL Open Font License is in OFL.txt.

Regenerate it from the upstream OTF with tools/generate_tw_chat_font.py.

Source: https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/OTF/TraditionalChinese
